# how to run this bot for the first time

## step-by-step

1. Go to the folder where you extracted TBS (on macOS, the Applications folder).
2. Double-click **TravianBotSharp.exe** (on macOS and Linux, **TravianBotSharp**).
3. Wait for the main window to open.
4. If this is your first time, start by adding an account.

## common issues

- If the app does not start, make sure you downloaded the package for your system (Windows, macOS or Ubuntu).
- On macOS the first launch is blocked because the app is not notarized: open **System Settings > Privacy & Security** and click **Open Anyway**.
- If you see a Chrome version warning, update Chrome and start TBS again.
